# Illustration Todo

A Vite + React todo app with a Hono API server and Drizzle schema.

## Setup

```bash
npm install
npm run dev
```

The Vite client runs on `http://localhost:5173` and the API server runs on `http://localhost:8787`.

## Build

```bash
npm run build
```

For Turso, set `TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN` before running `npm run db:push`.
